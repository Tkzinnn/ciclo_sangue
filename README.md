# CicloSangue — protótipo demonstrativo

Protótipo web responsivo para apresentar uma ideia de apoio à jornada de doação de sangue, inspirado na imagem e nos pontos levantados na entrevista local.

## Como abrir

Abra `index.html` em um navegador atualizado. Não há instalação ou servidor necessário. Para a apresentação, recomenda-se usar Chrome ou Edge e manter o armazenamento local habilitado.

## O que é possível demonstrar

- Criar cadastro demonstrativo, sair e entrar novamente com e-mail e senha.
- A página inicial, informações e lista de unidades podem ser exploradas sem conta; login/cadastro são opcionais até iniciar um agendamento ou abrir áreas pessoais.
- Navegação entre início, agendamento, locais, histórico, informações, notificações e perfil.
- Busca e seleção de uma unidade; seleção de uma data e de um horário de exemplo; revisão e confirmação de um agendamento de demonstração.
- Edição do perfil e persistência local separada por conta para o perfil e os agendamentos neste navegador.
- Conteúdo adaptável a celular e desktop.

## Limites desta versão

Este é um protótipo de front-end. O cadastro e o login são apenas uma simulação local e não representam autenticação segura: não há servidor, recuperação de senha ou verificação de identidade. Não use senhas, dados pessoais ou dados de saúde reais. Não há integração com cadastro ou sistemas do hemocentro, envio de agendamentos, notificações externas, mapas conectados ou registro oficial de doações. As unidades e opções de horário são exemplos; endereços e funcionamento devem ser confirmados. O aplicativo não avalia aptidão, não recomenda intervalos nem substitui orientações profissionais.

Os cadastros, a sessão e os dados de demonstração são guardados no armazenamento local do navegador. Apagar os dados do site/navegador remove as contas da demonstração.
